# Голосовой сумматор — Android-приложение

Держит в памяти последние 10 продиктованных чисел и их сумму. При 11-м числе
самое старое число уходит с «ленты».

## Как получить APK и поставить на телефон

### Способ А — без установки Android Studio (через GitHub, из браузера)

1. Зайдите на github.com, создайте новый **пустой** репозиторий (New repository),
   например `voice-adder`. Ничего не отмечайте («Add README» и т.п. — не нужно).
2. На странице пустого репозитория нажмите **uploading an existing file** и
   перетащите туда всё содержимое этой папки (включая скрытую папку `.github` —
   если drag-and-drop её не подхватит, создайте файл
   `.github/workflows/build-apk.yml` вручную через "Add file → Create new file"
   и вставьте его содержимое).
3. После того как файлы закоммичены, откройте вкладку **Actions** в репозитории.
   Сборка запустится автоматически (или нажмите "Run workflow", если видите
   такую кнопку у workflow "Build APK").
4. Дождитесь зелёной галочки (обычно 2–4 минуты). Откройте завершённый прогон,
   внизу страницы будет **Artifacts → voice-adder-debug-apk** — скачайте zip,
   внутри лежит `app-debug.apk`.
5. Перекиньте `app-debug.apk` на телефон (через Google Drive, Telegram себе,
   USB-кабель и т.п.) и откройте файл на телефоне.
6. Android спросит разрешение "Установить неизвестное приложение" для того
   приложения, через которое вы открыли файл (Файлы / Chrome / Telegram) —
   разрешите один раз, и установка пройдёт как обычно.
7. При первом запуске разрешите доступ к микрофону.

### Способ Б — через Android Studio (если она у вас есть или готовы поставить)

1. Скачайте и установите [Android Studio](https://developer.android.com/studio).
2. File → Open → укажите папку проекта (эту).
3. Дождитесь синхронизации Gradle (Android Studio сама предложит скачать
   недостающий Gradle wrapper — согласитесь).
4. Подключите телефон по USB с включённой "Отладкой по USB" (Настройки →
   О телефоне → 7 раз тапнуть "Номер сборки" → в новых "Настройках
   разработчика" включить USB-отладку), либо просто нажмите Run ▶ и выберите
   эмулятор.
5. Нажмите зелёную кнопку Run ▶ — приложение соберётся и установится на
   телефон напрямую.
6. Готовый `.apk` также можно получить через Build → Build App Bundle(s) /
   APK(s) → Build APK(s) — файл появится в
   `app/build/outputs/apk/debug/app-debug.apk`.

## Структура проекта

- `app/src/main/java/com/example/voiceadder/MainActivity.kt` — экран (Jetpack Compose)
- `app/src/main/java/com/example/voiceadder/NumberParser.kt` — разбор чисел из речи
- `app/src/main/AndroidManifest.xml` — разрешения (микрофон)
- `.github/workflows/build-apk.yml` — облачная сборка APK
